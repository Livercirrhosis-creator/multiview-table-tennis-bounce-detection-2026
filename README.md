# 乒乓球多视角落点检测 · 2026

**从球轨迹到触台事件：面向不同拍摄视角的时序判断、落点定位与实时推理。**

SuperIntelligence 团队参加 2026 年“动感地带 AI+ 高校创智计划”AI 技术赛道的项目展示与技术归档。基于官方球检测器，本项目构建了三时间通道观测、密集／窗口双分支事件判断、缺测补点、桌框过滤及局部视觉校准，并完成最终部署和联合自测。

本仓库保存 **2026-11-10 最终验收版**的新增源码、模型身份、代表性实验与复现材料，于 2026-11-13 整理。每个视频独立处理；“多视角”指不同拍摄角度，“三通道”指三个时间通道，不是同步多摄像机融合。

## 实际做了什么

1. **在找球与触台之间建立完整事件决策。** 同一次检测前向利用多个时间通道；密集分支做事件分类，窗口分支判断事件存在并选帧，固定逻辑合并互补提名。
2. **处理缺测和真实视频时间轴。** 使用原生 PTS、有效观测与缺测标志；缺测路由两侧真实观测拟合并判断补点，避免把插补点循环当作原始证据，不把输入限制为固定 25 FPS。
3. **增加画面和空间证据。** 桌框模型提供保守空间过滤，局部视觉模型复核短名单候选，来源留出校准控制视觉证据强度并保持分支分数尺度。
4. **用可追溯实验取舍模块。** 来源分组训练、固定版本对照、事件增减与逐来源分析、模型及源码 SHA256 封存，兼顾效果与完整推理耗时。
5. **在目标环境完成等价提速。** RGB 归一化查表、真实时间戳解码线程与局部特征窗计算减少开销，最终输出与原版逐字节一致。

运行顺序：

```text
单视频 RGB + 原生时间戳
  → 官方找球 + 三时间通道观测
  → 密集事件分支（含局部视觉校准） / 窗口事件与选帧分支
  → 分支合并与时间冲突处理
  → 原始观测支持的缺测补点
  → 保守桌框过滤
  → 触台帧号与图像坐标
```

最终不默认运行 3D 或姿态分支。长视频上桌框过滤及视觉缓存有明确回退边界，详见 [技术路线与取舍](docs/DEVELOPMENT.md)。
