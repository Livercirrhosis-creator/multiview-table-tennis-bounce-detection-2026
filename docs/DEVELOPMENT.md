# 技术路线与研发取舍

项目围绕视频中的乒乓球触台时刻与图像落点展开，在已有球检测框架上逐步建立事件候选、分类、选帧、缺测补点和空间约束。最终保留的方案兼顾完整视频运行成本与跨来源参考效果；历史 3D、姿态和 ROI 支线保留研究记录，但没有全部进入最终推理链。

“多视角”指输入视频具有不同拍摄角度，推理仍逐视频独立完成，不是同步多摄像机重建。“三通道”指球检测器一次前向的不同时间通道；训练中的“原始／增强双视图”也是同一视频的两种观测表示，不代表新增独立视频。

## 最终实际运行的组件

| 阶段 | 实际作用与保留边界 |
| --- | --- |
| 球观测与真实时间轴 | 复用官方球检测前向与原生 PTS，利用另外的时间通道补充可靠球观测；保留原观测和原候选支持，不把补点当作原始测量。 |
| 密集事件分支 | 轻量膨胀时序卷积编码轨迹与上下文，对原生候选区分触台、击球、背景。新增可靠中心可进入密集分支。 |
| 窗口事件分支 | 判断窗口内是否存在事件，并在实际候选中选择位置；与密集分支互补，不等同于加入 3D。 |
| 校准局部视觉 | 对固定短名单读取多个时刻、两个尺度的 96×96 RGB 局部画面；MobileNetV3-small 的前部冻结、末端与事件头适配。标量校准抑制过强视觉证据，融合时保持与窗口分支可比较的分数尺度。 |
| 事件合并与缺测补点 | 合并分支、执行固定时间冲突处理；缺测模块仍从原始观测提名和判断，防止把插补证据循环当成真实支撑。 |
| 桌框过滤 | SSDLite320 MobileNetV3 桌框模型提供末端空间负证据。低置信、缺框或跨帧不一致时中性回退；长于 10 秒的视频跳过该桌过滤。 |
| 等价运行优化 | 改善真实时间戳解码并行、RGB 归一化与局部特征窗计算，在目标实例逐字节核对最终输出。 |

最终模型身份为 `VISUAL_CALIBRATED_SCALE_AWARE_FINAL154_V001`，视觉入口为 `participant.visual_calibration_v001.solution:Solution`；目标实例使用其等价提速包装 `participant.visual_fast_v002:Solution`。[模型封存与采用回执](../evidence/visual_calibration_decision.json) · [最终运行回执](../evidence/captain_final_release_receipt.json)

密集、窗口、缺测、桌框四模块先按固定配方在 154 段上做部署拟合；视觉模型随后同样拟合 154 段，视觉校准标量只使用原 121 段来源留出的预测。原 33 段已进入最终训练，不能再作为该版本的留出测试。[154 权重与数据用途](../evidence/final154_comparison.json) · [视觉训练与校准封存](../evidence/visual_calibration_decision.json)

| 时间 | 解决的问题 | 实际结果与取舍 |
| --- | --- | --- |

| 2026-11-10 | 局部视觉误杀原本高置信的触台候选 | 用嵌套来源分组生成校准证据，修正视觉强度与分支分数尺度。121 开发严格时间 F1 86.2886%→87.3999%；最终配对外部时空 F1 78.5321%→79.0108%、公开总分 87.6768→88.5942。提升主要来自少误报，存在命中损失。[开发证据](../evidence/visual_calibration_research.json) · [最终配对](../evidence/visual_calibration_final_scores.json) |
| 2026-11-10 | 目标实例速度余量较小 | 在输出逐字节相同的条件下接入等价优化，最终联合自测乒乓球 53.0 FPS、公开本地 88.3180。研发实例的 61.4 FPS 单列，未将跨实例差异称为稳定加速。[目标验收](../evidence/captain_final_public_score.json) · [运行回执](../evidence/captain_final_release_receipt.json) |

## 研发方法中值得保留的部分

训练与评价以来源分组，避免同源切片跨折；增强、遮挡副本与相邻窗口按原物理事件组织，不能扩大为独立样本数。视觉校准在每个外折的训练来源内再划分内折，用未参与对应视觉模型训练的来源产生校准证据；最终使用同一固定配方部署，不按外部逐例错误改门槛。

每轮不仅比较 F1，还记录恢复和丢失事件、逐来源变化及实际成本。公开 15 段与外部 130 段均有历史曝光，保留各自用途和标注边界；最终 154 拟合明确记录原 33 段转入训练的时点。完整模型运行、缓存回放和训练耗时分别报告。

推理包、源码、权重与输出通过 SHA256 关联；运行保留完成状态、退出码、原始预测与评分证据。等价优化以实际特征或最终输出一致性为依据，不能用一次运行较快就推断算法加速。[最终回执](../evidence/captain_final_release_receipt.json)

## 已知缺口与未采用方向

最终视觉方案减少误报的同时也减少部分命中。外部参考标注存在不确定性，困难接触、遮挡和精确坐标仍有改进空间；新增视觉的收益也不是所有来源一致。结果的完整边界见 [RESULTS.md](RESULTS.md)。

3D、姿态、概率集成、来源等权重训、时刻校正和 ROI 重建等曾有独立实验；它们不能因为存在于代码历史中就被写进最终架构。最终包内可能保留历史依赖，展示以实际入口和调用链为准。桌框过滤对长片回退，局部视觉在帧缓存超限时回退到原三通道链；本批测试没有证明这些回退条件下仍能取得同样增益。
